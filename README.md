# 🎬 Análise Exploratória de Dados da Netflix (Netflix EDA)

Este projeto faz parte do meu portfólio de Ciência de Dados. O objetivo foi realizar uma Análise Exploratória de Dados (EDA) utilizando Python para extrair insights valiosos sobre o catálogo de filmes e séries da Netflix disponível no Kaggle.

---

## 🛠️ Tecnologias e Ferramentas Utilizadas
* **Linguagem:** Python
* **Biblioteca de Manipulação:** Pandas
* **Bibliotecas de Visualização:** Matplotlib e Seaborn
* **Ambiente:** VS Code (Jupyter Notebooks)
* **Controle de Versão:** Git e GitHub

---

## 📊 Principais Perguntas e Insights Respondidos
1. **Filmes vs. Séries:** O catálogo é dominantemente composto por **Filmes** (mais de 6.000 títulos), superando com folga o formato de séries.
2. **Países Produtores:** Os **Estados Unidos** lideram isoladamente o ranking de volume de produções na plataforma.
3. **Evolução Temporal:** Houve um crescimento acelerado e constante nos lançamentos até meados de 2018/2019.
4. **Classificação Indicativa:** A categoria **TV-MA** (conteúdo voltado para o público adulto) é a predominante no catálogo geral.
